# All You Need is Trust: A Longitudinal Analysis of Italy’s OpenID Federation Journey

This repository contains the following supplementary material for the paper _All You Need is Trust: A Longitudinal Analysis of Italy’s OpenID Federation Journey_:
- Our self-developed tooling for retrieval and analysis
- The dataset the paper is based on
